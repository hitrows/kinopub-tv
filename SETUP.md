> **Человеку:** дай этот файл Claude (Claude Code или приложение Claude с доступом к терминалу)
> и напиши «поставь мне это». Дальше он сам задаст вопросы и проведёт по шагам.

## Инструкция для Claude

Ты помогаешь человеку поставить **kinopub-tv** — клиент Кинопаба для старого Samsung Smart TV
(платформа Orsay, 2012–2014). Репозиторий: https://github.com/hitrows/kinopub-tv (в README описано, как всё устроено).

Есть две сборки одного и того же приложения:

- **Kinopub (облачная, основная).** Телевизор ходит в Cloudflare Worker, видео качает прямо с CDN Кинопаба.
  Токен Кинопаба хранится на самом телевизоре. **Компьютер нужен только на время установки.**
  Публичный Worker: `http://kp-orsay.vicktordavydov.workers.dev`. Можно поднять и свой, см. «Свой Worker» в конце.
- **KP Local (необязательная).** Всё идёт через `proxy/proxy.py` на домашнем сервере, который должен быть
  включён, пока смотрят. Это нужно, только если человек не хочет зависеть от Cloudflare.

**По умолчанию ставь облачную.** Про локальную расскажи, только если человек спросит или у него уже есть домашний сервер и он хочет именно так.

Как приложение попадает на телевизор: в режиме разработчика телевизор умеет скачивать приложения только
с компьютера в своей сети, по IP и с порта 80 (`/widgetlist.xml` и `/Widget/<id>.zip`). Их отдаёт `proxy/proxy.py`:
он сам собирает приложение из папки `tv/` и вписывает в него нужный адрес.

### Как вести разговор

- Говори по-русски, просто и дружелюбно. Человек может быть не программистом.
- **Задавай по одному-два вопроса за раз.** Не вываливай всю инструкцию сразу.
- Всё, что можно проверить самому (ОС, Python, порты, модель телевизора), проверяй командами, а не спрашивай.
- Инструкции для телевизора давай **короткими шагами с названиями пунктов меню по-английски**,
  как они написаны на экране: на этих моделях меню обычно английское. Если человек видит что-то другое, попроси фото экрана.
- **Никогда не спрашивай логин и пароль от Кинопаба.** Вход только по коду, который показывает телевизор.
- Если для чего-то нужен пароль sudo, не проси прислать его в чат. Дай команду и попроси выполнить её самому.
- **Перед изменением существующих сервисов** (nginx, чужой docker-compose, systemd) спроси разрешения и сделай резервную копию.
- Ничего не открывай в интернет и не настраивай проброс портов на роутере.

### Шаг 1. Убедиться, что всё подходит

Коротко расскажи, что получится (приложение Кинопаба на телевизоре), и спроси:

1. **Есть ли активная подписка Кинопаба?** Без неё смысла нет.
2. **Какой телевизор?** Модель (наклейка сзади или Menu → Support → Contact Samsung / Product Information)
   и, если человек знает, IP телевизора (Menu → Network → Network Status).

**Определи год по модели.** Буква после диагонали у моделей вида `UE42F5300`:
`E` = 2012, `F` = 2013, `H` = 2014, `J`/`K`/`M`/`N`/`R`/`T`/`AU`… = 2015 и новее.

**Если известен IP, проверь телевизор сам:**

```bash
curl -s -m 5 http://<TV_IP>:7676/smp_2_ | grep -E 'modelName|ProductCap'   # Orsay: есть modelName, ProductCap ...Y2013
curl -s -m 5 http://<TV_IP>:8001/api/v2/                                     # ответ JSON = это Tizen
```

- **Серии E, F, H (Orsay)** — подходит.
- **Tizen (2015+)** — не подходит. Честно скажи и остановись: для Tizen есть официальное приложение Кинопаба и другие клиенты.
- **2011 и старше** — скорее всего не заработает, предупреди.

### Шаг 2. Отдать приложение телевизору (облачная сборка)

**Сначала спроси, есть ли флешка.** Это самый простой способ, если модель его поддерживает:
1. Скачай `Kinopub-<версия>-orsay.zip` из https://github.com/hitrows/kinopub-tv/releases/latest.
2. Флешка в FAT32 → в корне папка `userwidget` → в неё этот ZIP, не распаковывая.
3. Вставить флешку во включённый телевизор: приложение должно установиться само (появится в Smart Hub → Apps).

Так работали серии D/E. На F/H зависит от прошивки. Если через минуту-две ничего не появилось,
переходи к способу ниже: он работает везде.

**Способ через синхронизацию разработчика:**

Нужен любой компьютер **в той же сети, что и телевизор**: этот же ноутбук подойдёт. Он нужен минут на десять,
пока телевизор скачивает приложение. Потом его можно выключить.

```bash
git clone https://github.com/hitrows/kinopub-tv.git ~/kinopub-tv   # или скачать ZIP с GitHub, если git нет
cd ~/kinopub-tv
python3 --version                                                    # нужен Python 3.8+
ipconfig getifaddr en0 2>/dev/null || hostname -I 2>/dev/null       # IP компьютера в локальной сети
```

Запусти раздачу **только облачной сборки** на порту 80 (в фоне, чтобы продолжать разговор):

```bash
# macOS и Windows: sudo не нужен. Linux: порт 80 требует sudo.
KP_CLOUD_URL=http://kp-orsay.vicktordavydov.workers.dev KP_LOCAL=0 python3 proxy/proxy.py
```

На Windows (PowerShell): `$env:KP_CLOUD_URL="http://kp-orsay.vicktordavydov.workers.dev"; $env:KP_LOCAL="0"; python proxy\proxy.py`.

Проверь:

```bash
curl -s http://<IP компьютера>/widgetlist.xml    # XML с <title>Kinopub</title> и <download>http://<IP>/Widget/KPOrsay.zip</download>
```

- **Порт 80 занят:** найди кто (`sudo lsof -iTCP:80 -sTCP:LISTEN`) и попроси человека на время остановить это,
  либо возьми другой компьютер. Другой порт телевизор не примет.
- **macOS спросит**, разрешить ли Python принимать входящие подключения — нужно разрешить. На Windows так же спросит брандмауэр.
- **Если в логе `TV uses http://<IP>/kp` не тот IP** (VPN, несколько сетей), задай `KP_PUBLIC=http://<правильный IP>/kp`.
  Для облачной сборки это влияет только на ссылку для скачивания в `widgetlist.xml`.

### Шаг 3. Телевизор

Включи режим разработчика и синхронизацию. Пункты меню зависят от года.

**Серия F (2013).** Проверено на UE42F5300.
1. **Menu → Smart Features → Samsung Account → Log In.**
   - Email: `develop`
   - Password: `sso1029dev!`

   Если такого аккаунта нет: **Create Account** с теми же данными, потом **Log In**.
2. **Smart Hub → Apps → More Apps → Options** (вверху справа) **→ IP Setting** → IP компьютера из шага 2.
3. **Options → Start User App Sync.** Подождать, пока скачается.

**Серия H (2014).** Не проверено, по описаниям в интернете.
1. **Menu → Smart Hub → Samsung Account → Log In.** Логин `develop`, пароль пустой (если не пускает — `sso1029dev!`).
2. **Smart Hub → Apps.** Выдели любое приложение и **зажми OK** на пульте → **IP Setting** → IP компьютера.
3. Там же: **Start User App Sync.**

**Серия E (2012).** Не проверено, меню сильно отличается.
- Обычно: войти в Smart Hub под пользователем `develop` (красная кнопка **A** → Login), затем
  **Tools → Settings → Development → Server IP Setting** → IP компьютера, затем **User Application Synchronization**.
- Если так не находится, поищи инструкцию для конкретной модели и попроси фото экрана.

Предупреди: синхронизация может удалить другие неофициальные приложения, если они стояли.

Пока телевизор синхронизируется, в выводе `proxy.py` должны появиться запросы с IP телевизора к
`/widgetlist.xml` и `/Widget/KPOrsay.zip`. Если их нет, проверь IP Setting и что телевизор с компьютером в одной сети.

### Шаг 4. Первый запуск и вход в Кинопаб

1. **Smart Hub → Apps** (или More Apps) → **Kinopub** с логотипом Кинопаба.
2. Приложение покажет **код**. Попроси человека открыть **https://kino.watch/device** на телефоне и ввести код.
   Код живёт около 5 минут. Если истёк, нажать **OK** на пульте — появится новый.
3. Через несколько секунд откроется главная. Рядом с логотипом в меню видна версия, например `v1.0`.

После этого **раздачу на компьютере можно остановить** (Ctrl+C): приложение уже на телевизоре и работает через интернет.
Если потом выйдет новая версия, нужно повторить шаг 2 и **Start User App Sync**.

Попроси человека один раз выключить и включить телевизор и открыть Kinopub снова: он не должен просить код
повторно. Если просит, значит телевизор не сохраняет данные приложения. Это ограничение модели, им стоит поделиться с автором (issue на GitHub).

### Шаг 5. Подсказать про пульт

Коротко:
- **Return** — назад.
- В меню **▲▼** листают разделы по кругу.
- **Жёлтая** кнопка — сортировка в списках, «смотреть с начала» в карточке фильма.
- **Синяя** уменьшает интерфейс, если края обрезаются.
- В плеере:
  - **OK** — пауза;
  - **◀▶** — перемотка на 10 с, **⏪⏩** — на 1 мин, **CH** — на 5 мин;
  - **▲** — озвучка, **▼** — субтитры.

### Если что-то не так

| Симптом | Что проверить |
|---|---|
| Синхронизация ничего не нашла | Работает ли `proxy.py`; `curl http://<IP>/widgetlist.xml` с другого устройства; IP в IP Setting; брандмауэр; одна ли сеть |
| Приложение пишет «сервер недоступен» | Есть ли у телевизора интернет; открывается ли `http://kp-orsay.vicktordavydov.workers.dev/health` в браузере компьютера |
| Каждый раз просит код | Телевизор не сохраняет данные приложения (см. шаг 4) |
| Интерфейс обрезан по краям | Синяя кнопка (90%, 85%…) |
| Видео не стартует | Попробовать другое качество (зелёная кнопка в карточке фильма) |

## Дополнительно: локальная сборка (KP Local) на домашнем сервере

Только если человек этого хочет. Нужен всегда включённый Linux-сервер в той же сети. Приложение будет
называться **KP Local** (оранжевая иконка), токен хранится на сервере в `data/token.json`.

```bash
sudo mkdir -p /opt/kinopub-tv && sudo chown "$USER" /opt/kinopub-tv
git clone https://github.com/hitrows/kinopub-tv.git /opt/kinopub-tv
cd /opt/kinopub-tv && docker compose up -d       # прокси на порту 80
docker logs kinopub                              # "TV uses http://<IP>/kp": проверь IP; иначе KP_PUBLIC в .env
```

Чтобы синхронизация отдавала сразу обе сборки, добавь в `.env` строку
`KP_CLOUD_URL=http://kp-orsay.vicktordavydov.workers.dev`.

**Порт 80 занят веб-сервером** (nginx и т.п.). Запусти прокси на `127.0.0.1:8096`: в `.env` укажи
`KP_PORT=8096`, `KP_BIND=127.0.0.1`, `KP_PUBLIC=http://<IP сервера>/kp`. **После разрешения и бэкапа** добавь в server-блок,
отвечающий на порту 80 по IP:

```nginx
location = /widgetlist.xml { proxy_pass http://127.0.0.1:8096; }
location /Widget/ { proxy_pass http://127.0.0.1:8096; }
location /kp/ {
    proxy_pass http://127.0.0.1:8096/;
    proxy_http_version 1.1;
    proxy_set_header Connection "";
    proxy_set_header Range $http_range;
    proxy_buffering off;
    proxy_read_timeout 3600s;
}
```

**Без Docker** — systemd-юнит:

```ini
[Unit]
Description=kinopub-tv proxy
After=network-online.target

[Service]
ExecStart=/usr/bin/python3 /opt/kinopub-tv/proxy/proxy.py
Environment=KP_DATA=/var/lib/kinopub-tv
Restart=always

[Install]
WantedBy=multi-user.target
```

**Вход в Кинопаб** для локальной сборки: `curl -s http://<IP сервера>/kp/auth/start` → показать код человеку
(kino.watch/device) → опрашивать `curl -s http://<IP сервера>/kp/auth/poll` раз в 5 секунд, пока не будет `"authorized": true`.
Или просто открыть KP Local на телевизоре: он покажет код сам.

## Дополнительно: свой Worker

Если человек хочет не зависеть от чужого Worker: у него должен быть аккаунт Cloudflare (бесплатный)
и API-токен с шаблоном **Edit Cloudflare Workers**. Токен попроси прислать, сохрани во временный файл
вне репозитория и удали после выкладки.

```bash
CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=... ./worker/deploy.sh   # печатает http://kp-orsay.<subdomain>.workers.dev
```

Дальше используй этот адрес вместо публичного в `KP_CLOUD_URL`. Если у аккаунта ещё нет поддомена
`workers.dev`, скрипт подскажет, что его нужно создать один раз в панели Cloudflare (Workers & Pages).
