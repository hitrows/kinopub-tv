# kinopub-tv

Неофициальный клиент [Кинопаба](https://kino.pub) для старых телевизоров Samsung Smart TV
на платформе **Orsay** (модели 2012–2014 годов: серии E, F, H).

Официального приложения для этих телевизоров нет, а их браузер не умеет современный HTTPS.
Поэтому приложение ходит в Кинопаб через маленький посредник — Cloudflare Worker,
а видео качает прямо с CDN Кинопаба. Свой сервер для просмотра не нужен.

> **Быстрая установка.** Дай файл [SETUP.md](SETUP.md) Claude (Claude Code или приложение Claude
> с доступом к терминалу) и напиши «поставь мне это». Он проверит телевизор, поставит приложение
> и подскажет, что нажимать на пульте.

## Что умеет

- **Главная:** первой полкой «Продолжить просмотр» (OK — сразу с места остановки), дальше «Для тебя» и полки как на сайте.
- **Разделы:** Новинки, Фильмы, Сериалы, Аниме, Концерты, Докуфильмы, Докусериалы, ТВ-шоу.
  Сортировка: новые / популярные / лучшие.
- **Для тебя** — рекомендации TMDB по истории просмотров, по полке на категорию.
- **История, Закладки** (с папками).
- **Поиск** с экранной клавиатурой как на Mac: ЙЦУКЕН и QWERTY.
- **Сериалы:** сезоны, отметки просмотренного, автопереход на следующую серию.
- **Плеер:**
  - продолжение с места остановки (синхронизируется с другими устройствами Кинопаба);
  - выбор озвучки и субтитров;
  - качество 1080p / 720p / 480p;
  - кадр без растягивания;
  - автопереподключение при обрыве;
  - «Следующая серия через 10 с» в конце серии.
- **Вход по коду** на kino.watch/device. Пароль от Кинопаба никуда не вводится.

## Что нужно

- **Samsung Smart TV 2012–2014** (Orsay). На телевизорах с Tizen (2015+) не работает: для них есть другие клиенты.
  Проверено на UE42F5300 (2013, серия F).
- **Активная подписка Кинопаба.**
- **Для установки:** флешка или любой компьютер в той же сети, что и телевизор (только на время установки).

## Две сборки

| | **Kinopub** (основная) | **KP Local** |
|---|---|---|
| Через что ходит | Cloudflare Worker ([worker/](worker/)) | `proxy/proxy.py` на домашнем сервере |
| Токен Кинопаба | хранится на телевизоре | хранится на сервере |
| Видео | прямо с CDN Кинопаба по HTTP | через домашний сервер |
| Что нужно, чтобы смотреть | только интернет | включённый домашний сервер |
| Иконка, версия в меню | белая, `v1.0` | оранжевая, `v1.0L` |

## Установка

### С флешки (не проверено на всех моделях)

1. Скачай `Kinopub-<версия>-orsay.zip` из [последнего релиза](https://github.com/hitrows/kinopub-tv/releases/latest).
2. На флешке (FAT32) создай в корне папку `userwidget` и положи туда этот ZIP, не распаковывая.
3. Вставь флешку во включённый телевизор. Приложение должно установиться само и появиться в Smart Hub → Apps.

Так ставились пользовательские приложения на сериях D/E. На F/H это зависит от прошивки.
Если не сработало, используй способ ниже.

### Через синхронизацию разработчика

На любом компьютере в той же сети (нужен Python 3.8+; на Linux — `sudo` для порта 80):

```bash
git clone https://github.com/hitrows/kinopub-tv.git
cd kinopub-tv
KP_CLOUD_URL=http://kp-orsay.vicktordavydov.workers.dev KP_LOCAL=0 python3 proxy/proxy.py
```

**На телевизоре (серия F, 2013):**
1. **Menu → Smart Features → Samsung Account → Log In**: логин `develop`, пароль `sso1029dev!`.
2. **Smart Hub → Apps → More Apps → Options → IP Setting** → IP компьютера.
3. **Options → Start User App Sync.** В Apps появится **Kinopub**. После этого компьютер можно выключить.

Для серий E и H пункты меню называются иначе, подробности в [SETUP.md](SETUP.md).

При первом запуске приложение покажет код, его нужно ввести на [kino.watch/device](https://kino.watch/device).

### KP Local на домашнем сервере

`docker compose up -d` на сервере, прокси займёт порт 80. Если порт занят, есть вход по коду и прочие подробности —
в разделе «Локальная сборка» в [SETUP.md](SETUP.md).

## Обновления

Облачная сборка обновляется сама: при запуске приложение спрашивает у Worker номер свежей версии и,
если она новее установленной, загружает её код. Без интернета запускается установленная копия.
Переустанавливать приложение нужно, только если поменялись картинки или манифест приложения.

Сколько запросов Worker израсходовал (лимит бесплатного тарифа Cloudflare — 100 000 в сутки):
`CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=... ./worker/usage.sh`.

Выпустить обновление (автор): `./release-cloud.sh`. Скрипт поднимает `VERSION`, коммитит и передвигает
git-метку `cloud`, с которой Worker отдаёт код. Обновление доходит до телевизоров за несколько минут.

## Как устроено

```
Kinopub:   Телевизор ──HTTP──▶ Cloudflare Worker ──HTTPS──▶ API Кинопаба
           Телевизор ──HTTP──────────────────────────────▶ CDN Кинопаба (видео)
KP Local:  Телевизор ──HTTP──▶ proxy.py (порт 80) ──HTTPS──▶ API и CDN Кинопаба
```

- `tv/` — приложение для телевизора (HTML/CSS/JS, только ES5: браузер телевизора на WebKit 2012 года).
  Одна кодовая база для обеих сборок. В облачной сборке токен хранится в `localStorage`, а если его нет —
  в файловом хранилище Orsay.
- `tv/index.html` — оболочка с загрузчиком: берёт свежий код с Worker (`/app/...`, из git-метки `cloud`)
  или запускает встроенную копию.
- `worker/` — Cloudflare Worker без хранения данных. Токен приходит с телевизора в заголовке `X-KP-Token`.
  В плейлистах куски видео переписываются на прямые HTTP-ссылки CDN. Выкладка: `worker/deploy.sh`.
- `proxy/proxy.py` — прокси на Python, только стандартная библиотека:
  - хранит токен Кинопаба в `data/token.json`;
  - переписывает все ссылки из API на себя;
  - пропускает только хосты Кинопаба;
  - собирает приложение для телевизора на лету, вписывая в него свой адрес.
- `VERSION` — версия приложения, она видна в меню рядом с логотипом.

### Настройки прокси (переменные окружения)

| Переменная | По умолчанию | Что это |
|---|---|---|
| `KP_PORT` | `80` | Порт |
| `KP_BIND` | `0.0.0.0` | Адрес, на котором слушать |
| `KP_PUBLIC` | `http://<LAN IP>[:порт]/kp` | Адрес, по которому телевизор ходит в прокси |
| `KP_DATA` | `./data` | Где хранить токен |
| `KP_CLIENT_ID`, `KP_CLIENT_SECRET` | публичные ключи Kodi-плагина Кинопаба | Клиент API |
| `KP_CLOUD_URL` | — | Адрес Worker: синхронизация отдаёт и облачную сборку |
| `KP_LOCAL` | `1` | `0` — отдавать только облачную сборку |

### Эндпоинты

| Путь | Что |
|---|---|
| `/widgetlist.xml`, `/Widget/<id>.zip` | Приложения для «Start User App Sync» (`KPOrsay` — Kinopub, `KinoPub` — KP Local) |
| `/kp/auth/start`, `/kp/auth/poll`, `/kp/auth/status` | Вход по коду устройства |
| `/kp/api/<path>` | Кинопаб `/v1/<path>`, ссылки переписаны на прокси |
| `/kp/s/<b64>/<имя>` | Поток файла с CDN (с поддержкой Range); `.m3u8` переписываются |
| `/kp/hls/<b64>/<n>/index.m3u8` | HLS с аудиодорожкой `n` |
| `/kp/srt/<b64>/subs.json` | Субтитры `.srt` в виде JSON |

## Особенности старых Samsung, на которые уже наступили

- **Экран 960×540.** Приложение рисуется в плоскости 960×540, вёрстка сделана под неё напрямую.
  Масштабировать через CSS transform нельзя: текст становится рваным.
- **Кеш файлов.** Телевизор кеширует файлы приложения по имени даже после переустановки, поэтому
  `app.js` и `app.css` в архиве называются `app-<версия>.*`.
- **Видео только через HLS.** Перемотка в середину mp4 размером в несколько гигабайт заставляет CDN думать
  больше минуты. HLS отдаётся кусками мгновенно, а озвучку можно выбрать через `index-v1-a<n>.m3u8`.
- **Ложный «конец» видео.** При обрыве связи плеер может сообщить, что фильм закончился. Если до конца
  больше 90 секунд, приложение переподключается, а не помечает фильм просмотренным.
- **Значки Unicode** вроде ⏪ шрифт телевизора не знает, поэтому иконки сделаны картинками.

## Разработка

- **Проверка интерфейса в браузере.** Запусти `python3 -m http.server -d tv` и открой
  `http://localhost:8000/?proxy=http://<сервер>/kp` в окне 960×540. Стрелки, Enter, Backspace работают как пульт,
  вместо плеера Samsung используется `<video>`.
- **Выкладка на сервер.** `./deploy.sh` поднимает `VERSION`, копирует `tv/` и `proxy/` по SSH и перезапускает
  прокси. Настройки берутся из `deploy.env`, формат описан в начале `deploy.sh`. На телевизоре после этого —
  **Start User App Sync**.
- **Диагностика.** Приложение шлёт события (ошибки, кнопки, события плеера) запросами `/kp/log?...`,
  их видно в логе прокси: `docker logs kinopub`.

## Дисклеймер

Проект не связан с Кинопабом. Нужна своя оплаченная подписка.

Рекомендации в разделе «Для тебя» строятся на данных [TMDB](https://www.themoviedb.org/).
This product uses the TMDB API but is not endorsed or certified by TMDB.

Телевизор не умеет HTTPS, поэтому запросы к Worker, включая токен Кинопаба в заголовке, идут по интернету
без шифрования. Worker ничего не хранит, но токен теоретически можно перехватить в чужой сети
(например, в публичном Wi-Fi). Локальный прокси рассчитан только на домашнюю сеть: не открывай его в интернет.
