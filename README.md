# kinopub-tv

Неофициальный клиент [Кинопаба](https://kino.pub) для старых телевизоров Samsung Smart TV
на платформе **Orsay** (модели 2012–2014 годов: серии E, F, H) плюс маленький прокси для домашнего сервера.

Официального приложения для этих телевизоров нет, а их браузер не умеет современный HTTPS.
Поэтому телевизор ходит к прокси в домашней сети по обычному HTTP, а прокси — к Кинопабу.

> **Быстрая установка.** Дай файл [SETUP.md](SETUP.md) Claude (Claude Code или приложение Claude
> с доступом к терминалу) и напиши «поставь мне это». Он спросит про сервер и телевизор, всё
> установит, поможет войти в Кинопаб и подскажет, что нажимать на пульте.

## Что умеет

- **Главная** с полками как на сайте: популярные и новые фильмы и сериалы, горячее, концерты, документальное.
- **Разделы:** Новинки, Фильмы, Сериалы, Аниме, Концерты, Докуфильмы, Докусериалы, ТВ-шоу.
  Сортировка: новые / популярные / лучшие.
- **Недосмотренное, История, Закладки** (с папками).
- **Поиск** с экранной клавиатурой как на Mac: ЙЦУКЕН и QWERTY.
- **Сериалы:** сезоны, отметки просмотренного, автопереход на следующую серию.
- **Плеер:**
  - продолжение с места остановки (синхронизируется с другими устройствами Кинопаба);
  - выбор озвучки и субтитров;
  - качество 1080p / 720p / 480p;
  - кадр без растягивания;
  - автопереподключение при обрыве.

## Что нужно

- **Samsung Smart TV 2012–2014** (Orsay). На телевизорах с Tizen (2015+) не работает: для них есть другие клиенты.
  Проверено на UE42F5300 (2013, серия F).
- **Компьютер или сервер в той же домашней сети, включённый, пока смотришь.**
  Подойдёт любой Linux с Docker или Python 3.8+: NAS, Raspberry Pi, старый ноутбук.
- **Активная подписка Кинопаба.**

## Ручная установка

На сервере:

```bash
git clone https://github.com/hitrows/kinopub-tv.git
cd kinopub-tv
docker compose up -d
```

Прокси слушает порт **80**: телевизор забирает список приложений только с него. Если порт 80 занят
(например, nginx), смотри раздел «Порт 80 занят» в [SETUP.md](SETUP.md).

Без Docker: `sudo python3 proxy/proxy.py` (для автозапуска — systemd, пример в SETUP.md).

**Вход в Кинопаб.** Открой `http://<IP сервера>/kp/auth/start`, введи показанный код на
[kino.watch/device](https://kino.watch/device). Можно и иначе: запустить приложение на телевизоре, и оно само покажет код.

**На телевизоре (серия F, 2013):**
1. **Menu → Smart Features → Samsung Account → Log In**: логин `develop`, пароль `sso1029dev!`.
2. **Smart Hub → Apps → More Apps → Options → IP Setting** → IP сервера.
3. **Options → Start User App Sync**. В Apps появится **KinoPub**.

Для серий E и H пункты меню называются иначе, подробности в [SETUP.md](SETUP.md).

## Как устроено

```
Телевизор ──HTTP──▶ proxy.py (порт 80) ──HTTPS──▶ API и CDN Кинопаба
```

- `tv/` — приложение для телевизора (HTML/CSS/JS, только ES5: браузер телевизора на WebKit 2012 года).
- `proxy/proxy.py` — прокси на Python, только стандартная библиотека:
  - хранит токен Кинопаба в `data/token.json`;
  - переписывает все ссылки из API на себя;
  - пропускает только хосты Кинопаба;
  - собирает приложение для телевизора на лету, вписывая в него свой адрес.
- `VERSION` — версия приложения, она видна в меню рядом с логотипом.

### Настройки прокси (переменные окружения)

| Переменная | По умолчанию | Что это |
|---|---|---|
| `KP_PORT` | `80` | Порт |
| `KP_BIND` | `0.0.0.0` | Адрес, на котором слушать |
| `KP_PUBLIC` | `http://<LAN IP>[:порт]/kp` | Адрес, по которому телевизор ходит в прокси |
| `KP_DATA` | `./data` | Где хранить токен |
| `KP_CLIENT_ID`, `KP_CLIENT_SECRET` | публичные ключи Kodi-плагина Кинопаба | Клиент API |

### Эндпоинты

| Путь | Что |
|---|---|
| `/widgetlist.xml`, `/Widget/KinoPub.zip` | Приложение для «Start User App Sync» |
| `/kp/auth/start`, `/kp/auth/poll`, `/kp/auth/status` | Вход по коду устройства |
| `/kp/api/<path>` | Кинопаб `/v1/<path>`, ссылки переписаны на прокси |
| `/kp/s/<b64>/<имя>` | Поток файла с CDN (с поддержкой Range); `.m3u8` переписываются |
| `/kp/hls/<b64>/<n>/index.m3u8` | HLS с аудиодорожкой `n` |
| `/kp/srt/<b64>/subs.json` | Субтитры `.srt` в виде JSON |

## Особенности старых Samsung, на которые уже наступили

- **Экран 960×540.** Приложение рисуется в плоскости 960×540, вёрстка сделана под неё напрямую.
  Масштабировать через CSS transform нельзя: текст становится рваным.
- **Кеш файлов.** Телевизор кеширует файлы приложения по имени даже после переустановки, поэтому
  `app.js` и `app.css` в архиве называются `app-<версия>.*`.
- **Видео только через HLS.** Перемотка в середину mp4 размером в несколько гигабайт заставляет CDN думать
  больше минуты. HLS отдаётся кусками мгновенно, а озвучку можно выбрать через `index-v1-a<n>.m3u8`.
- **Ложный «конец» видео.** При обрыве связи плеер может сообщить, что фильм закончился. Если до конца
  больше 90 секунд, приложение переподключается, а не помечает фильм просмотренным.
- **Значки Unicode** вроде ⏪ шрифт телевизора не знает, поэтому иконки сделаны картинками.

## Разработка

- **Проверка интерфейса в браузере.** Запусти `python3 -m http.server -d tv` и открой
  `http://localhost:8000/?proxy=http://<сервер>/kp` в окне 960×540. Стрелки, Enter, Backspace работают как пульт,
  вместо плеера Samsung используется `<video>`.
- **Выкладка на сервер.** `./deploy.sh` поднимает `VERSION`, копирует `tv/` и `proxy/` по SSH и перезапускает
  прокси. Настройки берутся из `deploy.env`, формат описан в начале `deploy.sh`. На телевизоре после этого —
  **Start User App Sync**.
- **Диагностика.** Приложение шлёт события (ошибки, кнопки, события плеера) запросами `/kp/log?...`,
  их видно в логе прокси: `docker logs kinopub`.

## Дисклеймер

Проект не связан с Кинопабом. Нужна своя оплаченная подписка. Прокси рассчитан только на домашнюю
сеть: не открывай его в интернет, через него идёт твой аккаунт.
